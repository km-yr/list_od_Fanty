# List do Psikołaja 🐾

Interaktywny list do Psikołaja od Fanty.

1. Na zimowym tle pojawiają się odciski psich łapek na śniegu.
2. Pojawia się napis „Przeczytaj list do Psikołaja”.
3. Po kliknięciu od razu widać cały list, wyśrodkowany, z tropami łapek po bokach.

## Pliki

- `index.html` – treść listu (zmieniasz ją bezpośrednio tutaj)
- `style.css` – wygląd
- `script.js` – animacje tropów

## Publikacja na GitHub Pages

1. Wrzuć pliki do repozytorium (np. `list-do-psikolaja`), tak aby `index.html` leżał w katalogu głównym.
2. **Settings → Pages** → „Deploy from a branch”, gałąź `main`, folder `/ (root)` → Save.
3. Strona będzie dostępna pod adresem `https://<twoj-login>.github.io/list-do-psikolaja/`.

Czcionka Patrick Hand ładuje się z Google Fonts, więc strona potrzebuje internetu, żeby wyglądała w pełni.
